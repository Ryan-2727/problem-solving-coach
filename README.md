# Problem Solving Coach

**从一道题出发，理解知识，掌握方法，举一反三。**

简体中文 · [English](README.en.md)

Problem Solving Coach 是一个面向大学理工科学生的 Codex Skill。它围绕你提供的题目梳理知识点，逐步解释解题思路，并提炼能够迁移到同类题目的方法。

> 解题入口 → 知识点 → 方法选择 → 逐步解答 → 迁移训练 → 考前总结

## 能帮你做什么

- **定位考点**：识别已知条件、题目要求和核心知识，区分必要知识与相关拓展。
- **先给入口，再讲解法**：先指出题目条件与第一步，再解释方法选择、适用边界和每一步的依据。
- **总结方法**：提炼题型识别信号、通用步骤、适用条件、快速技巧与常见错误。
- **迁移练习**：默认提供一道同类巩固题和一道考试变式题，并附完整解析。
- **适应你的需求**：支持只讲思路、重新解释难点、批改答案，以及结合教材或教师资料调整讲解。
- **按难度调整篇幅**：简单题压缩重复铺垫，复杂题展开必要推导；大量题目按题型整理并分批覆盖。

适用范围包括电路、数字与模拟电子技术、信号与系统、数字信号处理、通信原理、数学、C 语言、FPGA/VHDL 等本科理工科课程。

## 快速开始

将本仓库克隆到 Codex 的技能目录：

```bash
git clone https://github.com/Ryan-2727/problem-solving-coach.git ~/.codex/skills/problem-solving-coach
```

如果你的 Codex 使用自定义技能目录，请将目标路径改为该目录下的 `problem-solving-coach`。安装后，开始新的 Codex 会话并发送题目：

```text
使用 $problem-solving-coach 分析这道题，重点讲解解题方法：
[粘贴题目，或附上题目图片]
```

也可以说明你需要的帮助，例如“只讲思路”“这一步我没看懂”或“帮我批改我的解答”。

## 默认讲解流程

| 步骤 | 内容 |
| --- | --- |
| 1. 题目定位 | 先给解题入口，再梳理条件、目标与题型 |
| 2. 知识梳理 | 讲解核心知识，适度拓展关联考点 |
| 3. 考试考法 | 分析常见变式、学习优先级与易错点 |
| 4. 原题解答 | 解释方法选择与适用条件，逐步推导并检验 |
| 5. 方法模板 | 提炼可迁移的步骤、技巧与适用边界 |
| 6. 举一反三 | 设计同类巩固题与考试变式题 |
| 7. 练习解析 | 解释完整解法，并整理考前速记卡 |

讲解会根据题目难度和你的明确要求调整，重复知识只详细解释一次。大量题目会先列出覆盖清单，必要时分批处理并标明已完成和待处理题号。缺失或无法辨认的关键条件不会被凭空补造；考试重点判断也会以提供的材料为依据。
